# Nissi Fedora X — Portfolio

A multi-page personal portfolio website built strictly to modern HTML5 semantic standards and WCAG accessibility guidelines. No frameworks, no build step — plain HTML5, CSS3, and vanilla JavaScript.

## Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Hero intro, tech stack overview, featured project |
| About | `about.html` | Profile, education timeline, skills table, certifications |
| Projects | `projects.html` | Full project index with tech stacks and repo links |
| Contact | `contact.html` | Contact details + accessible, validated contact form |

## Features

- **Semantic HTML5** — `header`, `nav`, `main`, `section`, `footer`, and meaningful use of `dl`, `table`, and `ol` instead of generic `div`s
- **Accessibility (WCAG)** — skip-to-content link, visible focus states, `aria-current`, `aria-expanded`, `aria-live` form status, labeled and fieldset-grouped form fields, `prefers-reduced-motion` support
- **SEO** — unique title/meta description per page, canonical URLs, Open Graph tags, JSON-LD `Person` schema
- **Design** — custom SVG monogram mark, subtle dot-grid texture, and a terminal-style typing animation on the homepage hero (decorative only — the underlying text is static HTML, readable with JS off or by screen readers)

## Tech stack

HTML5 · CSS3 (custom properties, no framework) · Vanilla JavaScript · Google Fonts (Sora, IBM Plex Mono)
